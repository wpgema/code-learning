# 🚀 Code Learning Journey

Repository ini adalah dokumentasi perjalanan belajar pemrograman saya. Berisi kumpulan latihan, eksperimen, dan proyek mini dari berbagai bahasa pemrograman dan framework.

## 🎯 Tujuan
- **Melatih Logika:** Mempertajam kemampuan problem solving dan algoritma.
- **Dokumentasi:** Mencatat progres belajar dan referensi di masa depan.
- **Konsistensi:** Membangun kebiasaan coding (daily coding).
- **Persiapan Karir:** Portofolio untuk persiapan proyek nyata dan technical test.

## 📂 Struktur Project

Repository ini dikelompokkan berdasarkan topik dan teknologi:

### 🌐 Frontend & Web Design
Kumpulan landing page, profil perusahaan, dan portofolio.

- **Golang:**

- **PHP:** `php-oop-boilerplate` (OOP Concept)

### 💻 Computer Science & Algorithms
Implementasi struktur data fundamental.

### ☕ Object-Oriented Programming (OOP)
